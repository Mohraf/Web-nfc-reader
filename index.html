How it works

Passport and ID chips are smart cards. Before they share anything, the reader unlocks them with a key made from the MRZ or CAN (BAC or PACE). Then every command is encrypted.

Web NFC can't do itChrome's Web NFC only reads simple NDEF tags, so a passport looks empty. The WebToNative NFC add-on also returns tag text only.
The protocol runs here, in JavaScriptBAC, PACE, secure messaging and signature checks all run in this web app.
A tiny Android app passes messagesIt forwards chip commands and nothing else. The simulator runs the same code against a virtual chip.
